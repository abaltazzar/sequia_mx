# tests/ — pruebas automáticas

Verifican que los datos y funciones se comporten como se espera (por ejemplo,
que las proporciones sumen 1, que no haya municipios sin fechas). Se ejecutan con
`devtools::test()` y también en GitHub en cada push.

Si cambias una función y una prueba falla, o la función tiene un error o la
prueba quedó desactualizada; en ambos casos conviene revisarlo antes de subir.
